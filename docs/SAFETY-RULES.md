# Switch Safety Rules

1. Keep Switch a focused standalone app; multi-game experiments stay outside this branch.
2. Preserve the `switchScoreKeeper` browser-storage key and valid user-entered values.
3. Never present seeded people, scores, leagues, or matches as genuine user activity.
4. Make one independently tested behavior change per commit.
5. Never deploy from this work without a separately approved release and rollback checklist.
