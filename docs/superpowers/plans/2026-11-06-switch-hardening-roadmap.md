# Switch Hardening Roadmap

The approved design covers three independently reviewable subsystems. Implement them in this order so every stage leaves a working Switch-only app:

1. [Gameplay and source-baseline plan](2026-11-06-switch-gameplay-hardening.md) — create the focused development line, establish trustworthy tests, extract the rules engine and fix king-chain/AI behavior.
2. [Scorekeeper and competitions plan](2026-11-06-switch-scorekeeper-competitions.md) — preserve live browser data and implement the six Switch scoring formats.
3. [Experience and release-readiness plan](2026-11-06-switch-experience-release-readiness.md) — card movement, mobile/accessibility hardening, full verification and a deployment-safe handoff.

Production deployment is outside all three plans.
